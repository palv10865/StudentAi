📚 About

StudyMind AI is an intelligent tutor for BTech engineering students. It uses Google Gemini AI to provide step-by-step solutions, formula references, practice quizzes, and more.

Features: AI Chat • Math Rendering • Image/PDF Upload • Scientific Calculator • Unit Converter • Formula Sheet • Flashcards • Quizzes • Summarizer • Mind Maps • Periodic Table • Logic Gates

Keyboard Shortcuts:
• Ctrl+/ — Focus chat input
• Enter — Send message
• Shift+Enter — New line
• Esc — Close modal

🔑 Setup Your API Key

To use AI features, add a Gemini API key. It is stored on this device and sent directly to Google. Anyone with access to this app or device may be able to access it; use a personal key and restrict it in Google AI Studio where available.
